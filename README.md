# daisy-ning.github.io

Website of Yanrui Daisy Ning and the Subsurface Dynamics Lab, Clemson University.
Served by GitHub Pages at https://daisy-ning.github.io/

Plain HTML and CSS with no build step. Edit a page, commit and push in GitHub Desktop, and the live site updates within a couple of minutes. To preview, double-click any `.html` file.

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `research.html` | Research themes, fiber-sensing explainer, funded projects |
| `publications.html` | Journal articles, book chapters, conference papers |
| `group.html` | Lab members and how to join |
| `teaching.html` | Courses |
| `cv.html` | Web CV |
| `assets/css/style.css` | All colors, fonts and layout |
| `assets/js/site.js` | Pause/play button for the home page video |
| `Figs/` | Images and video |
| `sitemap.xml`, `robots.txt` | Help search engines find every page |
